SLTK PATCH CULT

INDEPENDENT ELECTRIBE MODDING LAB

HACK YOUR MACHINE. EXPAND YOUR SOUND.

SLTK PATCH CULT is an independent experimental project focused on creating plugins, tools and modifications for Korg Electribe hardware.

Our goal is to explore new possibilities, develop original tools and expand the creative potential of Electribe machines.

PROJECT COLLECTIONS

- SLTK ACID LAB — Acid-oriented tools and experiments.
- SLTK LIVE TOOLS — Tools for live performance.
- SLTK EXPERIMENTAL — Experimental concepts and prototypes.
- SLTK SEQUENCER TOOLS — Sequencing and workflow utilities.
